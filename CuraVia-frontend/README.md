# Curavia-frontend

Vite + React + TypeScript + Tailwind starter with Curavia chat UI and Login/Signup pages.

**Run all code in comand prompt**

### Quick start

```sh
npm install
npm run dev
```

Then open the URL printed in the terminal (usually http://localhost:5173).

#


### Run prettier check

```sh
# to check all errors caused by prettier
npx prettier --check "src/**/*.{ts,tsx,js,jsx,css}"

# to fix those errors
npx prettier --write "src/**/*.{ts,tsx,js,jsx,css}"
```
